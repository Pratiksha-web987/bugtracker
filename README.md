# AI Bug Tracker

AI Bug Tracker is a Spring Boot based web application for managing software projects and tracking bugs.

## Features

- User registration and login
- Role-based user management
- Project creation and management
- Internal and external project support
- Bug reporting and tracking
- Bug priority and severity management
- Bug assignment to users
- Bug status management
- Project-wise bug tracking
- Notifications and comments
- Automated testing support
- AI-based bug analysis support

## Technology Stack

- Java 25
- Spring Boot
- Spring Data JPA
- Spring Security
- Thymeleaf
- MySQL
- Maven
- Git & GitHub

## Project Purpose

The main purpose of this project is to provide a centralized platform for software project testing and bug management, with AI-based features for future automated bug detection and analysis.

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Configure MySQL database.
4. Update `application.properties` with your database credentials.
5. Run the Spring Boot application.
6. Open `http://localhost:8080` in a browser.
